# TicketMoa

### Description
> TicketMoa의 front-end를 담당하는 application입니다.

### Usage
```bash
$ npm run build    # react app build

$ npx -s <build directory> [-l <port>]

  serve@14.2.4

   │                                          │
   └──────────────────────────────────────────┘
```
