# TicketMoa

### Description
> TicketMoa의 front-end를 담당하는 application입니다.
> 
> Nginx를 Load Balancer로 활용하여 가용성을 높였습니다.

### Usage
```bash
$ docker compose up -d --build --force-recreate    
### multi staging을 적용하여 docker 내부에서 build dependency를 설치하고, build까지 이뤄지게 함 ###
```
